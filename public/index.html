선물 가격 갭

선택한 거래소에서 상장된 마켓 간 최대 가격 차이를 찾고, 마크 가격을 기초자산 1개 단위로 비교합니다. 갭 = 고가 − 저가, 갭 비율 = (고가 − 저가) ÷ 저가 × 100. 갭 축소 방향은 저가 거래소 롱·고가 거래소 숏이며, 펀딩비 기준 포지션과 반대일 수 있습니다.

마크 가격은 실제 매수·매도 호가가 아니므로 표시 갭은 체결 가능한 수익이 아닙니다. USDT0·USDC·USDe·USDH·USDG는 각각 1 USD로 가정합니다. 수신 시각이 2분 넘게 지났거나 양쪽 수신 시차가 30초를 넘으면 비교에서 제외합니다. 수신 시각은 가격 원본 갱신 시각을 보장하지 않습니다.

같은 시간을 비교합니다.

NADO: indexer의 24시간 비율 ÷ 24.
Variational: 공식 마켓 화면의 연율 비율 ÷ 8,760.
Hyperliquid·XYZ: API의 시간당 비율을 사용합니다(1시간 정산).
선택한 기간의 비율 = 시간당 비율 × 기간(시간).

Variational 공개 API 문서는 기간을 명시하지 않아 공식 웹앱의 연율 표시 및 환산식을 교차 확인했습니다. 정산 간격으로 연율을 다시 나누지 않습니다.

낮은 쪽에 롱, 높은 쪽에 숏.

동일 USD 명목금액으로 양쪽에 진입했을 때 시간당 펀딩비 차이 = 숏 거래소 비율 − 롱 거래소 비율입니다. Year는 복리를 적용하지 않은 APR이며, 총 투입 증거금 대비 수익률이 아닙니다. 1 BPS = 0.01%입니다.

Crypto / RWA 분류

기본은 Crypto입니다. RWA는 주식·ETF·지수·원자재·외환과 금 연동 토큰(PAXG·XAUT)을 포함합니다. ONDO 등 프로젝트 토큰은 Crypto로 분류합니다. 탭 선택은 선물 가격 갭과 펀딩비 화면에 함께 적용되며, 검색·거래소·즐겨찾기 필터와 조합할 수 있습니다. 상단 요약과 TOP 3는 선택 분류에 관계없이 기존 기준을 유지합니다.

거래소와 상장 종목

선택한 거래소의 전체 마켓을 표시하며, 미상장 칸은 -로 표시합니다. 2곳 이상 상장 필터를 켜면 선택 거래소 중 두 곳 이상에 상장된 종목만 표시합니다. 펀딩비는 최신 데이터 중 최저·최고 비율을 비교합니다. Hyperliquid 기본 마켓과 XYZ는 별도 열·필터로 비교합니다. XYZ의 xyz: 계약만 수집하며 다른 XYZ DEX는 제외합니다. 계약명은 셀 도움말과 상세 화면에서 확인할 수 있습니다. 기초자산이 확인된 티커만 통합하며 그 외에는 DEX 접두사를 유지합니다.

Lighter RH는 Robinhood Chain의 Lighter입니다. USDG 결제 마켓의 다음 1시간 예상 펀딩비를 표시하며, 기존 Lighter 메인넷은 별도 연결 대상입니다.

데이터와 이력

기본 마켓은 5초, Hyperliquid XYZ 마켓은 API 호출 한도를 고려해 30초 간격으로 조회합니다. 응답이 늦어지면 진행 중인 조회를 기다립니다. NADO는 원본 갱신 시각을 확인하며, Variational과 Hyperliquid는 펀딩비 갱신 시각을 제공하지 않아 수신 시각을 표시합니다. Lighter RH는 시장 통계 스트림의 원본 시각을 사용합니다. 호가 시각은 펀딩비 갱신 시각으로 사용하지 않습니다. 오류가 나거나 2분 이상 지난 데이터는 조합 계산에서 제외합니다.

Historical은 서버 실행 후 수집한 각 거래소 마켓의 관측값입니다. 약 1분마다 저장하여 최근 24시간을 유지합니다. 과거 정산 내역이나 실현 손익이 아닙니다. Hyperliquid·XYZ 이력은 분리 적용 후 관측부터 표시합니다. 이전 통합 이력은 계약 구분이 없어 새 차트에 연결하지 않습니다. 거래가 중단된 NADO 마켓은 제외합니다. kPEPE/kBONK/kSHIB는 각각 PEPE/BONK/SHIB에 대응시키며 가격은 1,000으로 나눕니다.

정산 간격과 남은 시간은 별개입니다. NADO의 다음 정산 시각은 API 값이며, Variational은 간격만 표시합니다. RWA 마켓의 휴장·특별 펀딩 규칙과 실제 체결 가능 여부는 해당 거래소에서 확인해야 합니다.
